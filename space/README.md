# paper-preflight online

Check every reference of a paper against Crossref, dblp, arXiv, DataCite, OpenAlex, Semantic
Scholar and PubMed: give an arXiv ID, upload a `.bib`, `.bbl`, `.tex`, `.txt` or `.pdf` file or
a `.zip` of a LaTeX project, or paste the reference list.

This Space runs the released [paper-preflight](https://github.com/amos689/paper-preflight)
package. Its source is the `space/` folder of that repository, synced on every release.
