# REF016 · identifier-available

**A DOI can be added** · 可以补充 DOI

| | |
|---|---|
| Severity · 严重度 | info · 提示 |
| Fix · 修复 | `bib fix` (the default, safe level) · `bib fix`（默认的 safe 级别） |

## English

Message:

    '{key}' has no DOI; {source} records {doi} for it. Adding it makes the reference unambiguous.

**What it checks.** The work's record has a DOI the entry lacks. Found once the entry is bound to its record by title, authors and year.

**When it can be wrong.** No case is known. If you meet one, please report it: false positives are the bugs we most want to hear about.

**What to do.** Add it: `bib fix` does at its safe level, the default.

To silence it for one entry once you have checked it, put a comment above the entry:

    % preflight: ignore[REF016] reason="..."

To turn it off for the whole project: `ignore-rules = ["REF016"]` in the project's settings.

## 中文

消息：

    条目 '{key}' 没有 DOI；{source} 记录的 DOI 是 {doi}。补上它可以让这条引用不再有歧义。

**检查什么。** 作品的记录中有 DOI，而条目没有。在条目按标题、作者和年份对应到记录之后给出。

**什么时候可能误报。** 目前没有已知的情形。如果遇到，请提交 issue：误报是我们最想知道的问题。

**怎么处理。** 补上它：`bib fix` 在默认的 safe 级别就会补上。

核对之后，如需对某个条目消除此规则，在条目上方加注释：

    % preflight: ignore[REF016] reason="..."

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["REF016"]`。
