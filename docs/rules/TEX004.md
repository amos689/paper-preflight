## English

Message:

    Source file could not be read: {detail}

**What it checks.** A source file that could not be opened: no permission, a broken link, a file another program holds. Its citations are not checked.

**When it can be wrong.** No case is known. If you meet one, please report it: false positives are the bugs we most want to hear about.

**What to do.** Fix the file's permissions or path, then check again.

To turn it off for the whole project: `ignore-rules = ["TEX004"]` in the project's settings.

## 中文

消息：

    源文件无法读取：{detail}

**检查什么。** 无法打开的源文件：没有权限、链接已损坏，或文件被其他程序占用。其中的引用没有被检查。

**什么时候可能误报。** 目前没有已知的情形。如果遇到，请提交 issue：误报是我们最想知道的问题。

**怎么处理。** 修正文件的权限或路径后重新检查。

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["TEX004"]`。
