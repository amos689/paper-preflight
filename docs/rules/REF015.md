# REF015 · preprint-published

**Preprint has been formally published** · 预印本已正式发表

| | |
|---|---|
| Severity · 严重度 | warning · 警告 |
| Fix · 修复 | `bib fix --level unsafe`: review the diff before applying it · `bib fix --level unsafe`：应用前请先检查差异 |

## English

Message:

    '{key}' cites a preprint that has been published in {found_venue} ({found_year}){doi_note}. Cite the published version and keep the eprint field.

**What it checks.** The entry cites a preprint (arXiv or another server) that has been published since, in a journal or proceedings: found through the DOI's relations, dblp, or a record with the same title and authors.

**When it can be wrong.** You may mean the preprint on purpose (content cut from the published version). A deposit of the paper's code or data is never counted as its publication.

**What to do.** Cite the published version and keep the eprint field: `bib fix --level unsafe` does it. To keep the preprint, silence it with the reason, or make the rule an info in the project's settings: `severity = { REF015 = "info" }`.

To silence it for one entry once you have checked it, put a comment above the entry:

    % preflight: ignore[REF015] reason="..."

To turn it off for the whole project: `ignore-rules = ["REF015"]` in the project's settings.

## 中文

消息：

    '{key}' 引用的预印本已正式发表于 {found_venue}（{found_year}）{doi_note}。建议改引正式版本，并保留 eprint 字段。

**检查什么。** 条目引用的预印本（arXiv 或其他预印本平台）已经正式发表在期刊或会议论文集上：通过 DOI 的关联关系、dblp，或标题和作者都相同的记录找到。

**什么时候可能误报。** 你可能有意引用预印本（例如正式版本删掉了相关内容）。论文代码或数据的存档不会被当作正式发表。

**怎么处理。** 改引正式版本并保留 eprint 字段：`bib fix --level unsafe` 可以自动完成。如果要保留预印本，可以注明原因后消除，或在项目设置中把它降为提示：`severity = { REF015 = "info" }`。

核对之后，如需对某个条目消除此规则，在条目上方加注释：

    % preflight: ignore[REF015] reason="..."

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["REF015"]`。
