**Run incomplete: some sources were unavailable** · 运行不完整：部分来源不可用

## English

Message:

    {count} reference(s) could not be fully checked because these sources were unavailable: {sources}. Results may change when you re-run later.

**What it checks.** Some sources did not answer and nothing could answer in their place, so some references were not fully checked. The run exits with code 2: the paper cannot be called clean yet.

**When it can be wrong.** No case is known. If you meet one, please report it: false positives are the bugs we most want to hear about.

**What to do.** Re-run later. Answers already received are cached, so the next run only asks what is missing.

To turn it off for the whole project: `ignore-rules = ["RUN001"]` in the project's settings.

## 中文

消息：

    有 {count} 条文献未能完整核查，因为以下来源不可用：{sources}。稍后重新运行，结果可能会变化。

**检查什么。** 部分来源没有应答，也没有其他来源能够代替，因此有些文献没有被完整核查。运行以退出码 2 结束：目前还不能认定论文没有问题。

**什么时候可能误报。** 目前没有已知的情形。如果遇到，请提交 issue：误报是我们最想知道的问题。

**怎么处理。** 稍后重新运行。已收到的答复都有缓存，下次运行只会补问缺少的部分。

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["RUN001"]`。
