**arXiv preprint withdrawn** · arXiv 预印本已撤回

| | |
|---|---|
| Severity · 严重度 | warning · 警告 |
| Fix · 修复 | none · 无 |

## English

Message:

    The arXiv preprint cited by '{key}' ({identifier}) has been withdrawn.

**What it checks.** arXiv lists the cited preprint as withdrawn by its authors.

**When it can be wrong.** No case is known. If you meet one, please report it: false positives are the bugs we most want to hear about.

**What to do.** Cite the version or the work that replaces it; a withdrawn preprint's earlier versions stay readable, but its authors no longer stand by it.

To silence it for one entry once you have checked it, put a comment above the entry:

    % preflight: ignore[REF018] reason="..."

To turn it off for the whole project: `ignore-rules = ["REF018"]` in the project's settings.

## 中文

消息：

    '{key}' 引用的 arXiv 预印本（{identifier}）已被撤回。

**检查什么。** arXiv 显示被引用的预印本已被作者撤回。

**什么时候可能误报。** 目前没有已知的情形。如果遇到，请提交 issue：误报是我们最想知道的问题。

**怎么处理。** 改引取代它的版本或作品；被撤回预印本的早期版本仍可阅读，但作者已不再认可其内容。

核对之后，如需对某个条目消除此规则，在条目上方加注释：

    % preflight: ignore[REF018] reason="..."

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["REF018"]`。
