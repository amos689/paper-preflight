## English

Message:

    Suppression of {rule} on '{key}' had no effect.

**What it checks.** A `% preflight: ignore[RULE]` comment that silenced nothing on its entry: the problem was fixed since, or the rule name is misspelt. Reported only once the rule has run on the entry; reference rules need a complete online run.

**When it can be wrong.** A source that stopped holding a record can make a reference rule fall silent for a run.

**What to do.** Delete the comment, or the rule from it.

To turn it off for the whole project: `ignore-rules = ["CFG001"]` in the project's settings.

## 中文

消息：

    对 '{key}' 的 {rule} 抑制没有起作用。

**检查什么。** `% preflight: ignore[规则]` 注释没有消除该条目的任何报告：问题已经改好，或者规则名拼错了。只有在该规则确实对这个条目运行过之后才报告；文献核查类规则需要一次完整的联网运行。

**什么时候可能误报。** 某个来源不再收录某条记录时，文献核查类规则可能在这次运行中没有触发。

**怎么处理。** 删掉这条注释，或从中删去该规则。

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["CFG001"]`。
