**Expression of concern or correction** · 关注声明或更正

| | |
|---|---|
| Severity · 严重度 | warning · 警告 |
| Fix · 修复 | none · 无 |

## English

Message:

    '{key}' has {notice} (reported by {sources}).

**What it checks.** The cited work has an expression of concern (a warning) or a published correction (an info), reported by Crossref, OpenAlex or PubMed.

**When it can be wrong.** No case is known. If you meet one, please report it: false positives are the bugs we most want to hear about.

**What to do.** Read the notice. Cite the correction too if it changes what you rely on.

To silence it for one entry once you have checked it, put a comment above the entry:

    % preflight: ignore[REF005] reason="..."

To turn it off for the whole project: `ignore-rules = ["REF005"]` in the project's settings.

## 中文

消息：

    '{key}' 有{notice}（依据：{sources}）。

**检查什么。** 被引作品有关注声明（警告）或已发布的更正（提示），依据来自 Crossref、OpenAlex 或 PubMed。

**什么时候可能误报。** 目前没有已知的情形。如果遇到，请提交 issue：误报是我们最想知道的问题。

**怎么处理。** 阅读该声明。如果更正影响到你引用的内容，请同时引用更正。

核对之后，如需对某个条目消除此规则，在条目上方加注释：

    % preflight: ignore[REF005] reason="..."

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["REF005"]`。
