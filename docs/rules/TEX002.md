**Include cycle** · 文件循环包含

| | |
|---|---|
| Severity · 严重度 | warning · 警告 |
| Fix · 修复 | none · 无 |

## English

Message:

    '{name}' is included recursively; the cycle was skipped.

**What it checks.** A file that includes itself, directly or through other files. LaTeX would loop; paper-preflight reads each file once.

**When it can be wrong.** A conditional around the `\input` (`\ifdefined`, a flag) is not evaluated: the cycle may never happen in a real build.

**What to do.** Remove the recursive include, or ignore the finding if a condition prevents it.

To turn it off for the whole project: `ignore-rules = ["TEX002"]` in the project's settings.

## 中文

消息：

    '{name}' 被循环包含，已跳过该循环。

**检查什么。** 某个文件直接或间接地包含了它自己。LaTeX 会陷入循环；paper-preflight 每个文件只读一次。

**什么时候可能误报。** `\input` 外面的条件判断（`\ifdefined`、开关变量）不会被求值：实际编译时这个循环可能根本不会发生。

**怎么处理。** 去掉递归的包含；如果条件判断会阻止它，可以忽略这条提示。

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["TEX002"]`。
