**Bibliography file missing or unreadable** · 参考文献文件缺失或无法读取

| | |
|---|---|
| Severity · 严重度 | error · 错误 |

## English

Message:

    Bibliography file '{path}' was not found or could not be read.

**What it checks.** A bibliography named by `\bibliography`, `\addbibresource` or `--bib` that does not exist or cannot be read. None of its entries is checked, and LaTeX will not find them either.

**When it can be wrong.** The file is made by a build step that has not run yet, or its path is built by a macro.

**What to do.** Correct the path or create the file. A generated bibliography is checked after the build, or passed with `--bib`.

To turn it off for the whole project: `ignore-rules = ["CIT005"]` in the project's settings.

## 中文

消息：

    找不到或无法读取参考文献文件 '{path}'。

**检查什么。** `\bibliography`、`\addbibresource` 或 `--bib` 指定的参考文献文件不存在或无法读取。其中的条目都没有被检查，LaTeX 同样找不到它们。

**什么时候可能误报。** 该文件由尚未运行的编译步骤生成，或者它的路径是由宏拼出来的。

**怎么处理。** 改正路径或补上文件。生成的参考文献文件可以在编译之后再检查，或用 `--bib` 传入。

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["CIT005"]`。
