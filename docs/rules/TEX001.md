**Included file not found** · 找不到被包含的文件

| | |
|---|---|
| Severity · 严重度 | warning · 警告 |
| Fix · 修复 | none · 无 |

## English

Message:

    Included file '{name}' was not found; citations in it are not checked.

**What it checks.** `\input`, `\include` or `\subfile` names a file that is not there. The citations in it are not checked.

**When it can be wrong.** The file is generated during the build, or its path depends on a macro paper-preflight does not expand.

**What to do.** Correct the path. For a generated file, check after the build or ignore the finding.

To turn it off for the whole project: `ignore-rules = ["TEX001"]` in the project's settings.

## 中文

消息：

    找不到被包含的文件 '{name}'，其中的引用未被检查。

**检查什么。** `\input`、`\include` 或 `\subfile` 指向的文件不存在。其中的引用没有被检查。

**什么时候可能误报。** 该文件在编译过程中生成，或者它的路径依赖 paper-preflight 不展开的宏。

**怎么处理。** 改正路径。生成的文件可以在编译之后再检查，或忽略这条提示。

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["TEX001"]`。
