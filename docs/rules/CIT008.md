**Field appears twice in an entry** · 条目中字段重复

| | |
|---|---|
| Severity · 严重度 | warning · 警告 |
| Fix · 修复 | none · 无 |

## English

Message:

    Field '{field}' appears more than once in '{key}'; only the first value is used.

**What it checks.** A field given twice in one entry (two `year` or two `doi` fields). Only the first counts, which may not be the one you corrected.

**When it can be wrong.** No case is known. If you meet one, please report it: false positives are the bugs we most want to hear about.

**What to do.** Delete the copy you do not mean.

To silence it for one entry once you have checked it, put a comment above the entry:

    % preflight: ignore[CIT008] reason="..."

To turn it off for the whole project: `ignore-rules = ["CIT008"]` in the project's settings.

## 中文

消息：

    条目 '{key}' 中字段 '{field}' 出现多次，只有第一个值生效。

**检查什么。** 同一条目中一个字段出现了两次（两个 `year` 或两个 `doi`）。只有第一个生效，而它未必是你改正过的那个。

**什么时候可能误报。** 目前没有已知的情形。如果遇到，请提交 issue：误报是我们最想知道的问题。

**怎么处理。** 删掉你不需要的那一份。

核对之后，如需对某个条目消除此规则，在条目上方加注释：

    % preflight: ignore[CIT008] reason="..."

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["CIT008"]`。
