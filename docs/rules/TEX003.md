## English

Message:

    Remote bibliography resource '{name}' is not checked.

**What it checks.** `\addbibresource[location=remote]{https://...}`: bibliographies are not downloaded, so its entries are not checked.

**When it can be wrong.** No case is known. If you meet one, please report it: false positives are the bugs we most want to hear about.

**What to do.** Download the bibliography and pass it with `--bib` to have it checked.

To turn it off for the whole project: `ignore-rules = ["TEX003"]` in the project's settings.

## 中文

消息：

    远程参考文献资源 '{name}' 不在检查范围内。

**检查什么。** `\addbibresource[location=remote]{https://...}`：远程参考文献不会被下载，因此其中的条目没有被检查。

**什么时候可能误报。** 目前没有已知的情形。如果遇到，请提交 issue：误报是我们最想知道的问题。

**怎么处理。** 下载该参考文献文件，用 `--bib` 传入即可检查。

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["TEX003"]`。
