**Identifier does not exist** · 标识符不存在

| | |
|---|---|
| Severity · 严重度 | error · 错误 |
| Fix · 修复 | none · 无 |

## English

Message:

    The {field} of '{key}' ({identifier}) does not exist: {authority} has no record of it.

**What it checks.** doi.org, arXiv or PubMed answers that the identifier does not exist: a typo, a DOI never registered, an invented arXiv ID.

**When it can be wrong.** A DOI registered in the last few days may not resolve yet.

**What to do.** Correct the identifier (a mistyped digit, a stray suffix) or remove it.

To silence it for one entry once you have checked it, put a comment above the entry:

    % preflight: ignore[REF002] reason="..."

To turn it off for the whole project: `ignore-rules = ["REF002"]` in the project's settings.

## 中文

消息：

    条目 '{key}' 的 {field}（{identifier}）不存在：{authority} 没有该标识符的记录。

**检查什么。** doi.org、arXiv 或 PubMed 答复该标识符不存在：拼写错误、从未注册的 DOI、编造的 arXiv 编号。

**什么时候可能误报。** 最近几天才注册的 DOI 可能还无法解析。

**怎么处理。** 改正标识符（打错的数字、多余的后缀）或将其删除。

核对之后，如需对某个条目消除此规则，在条目上方加注释：

    % preflight: ignore[REF002] reason="..."

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["REF002"]`。
