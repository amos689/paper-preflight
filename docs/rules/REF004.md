**Cited work has been retracted** · 被引作品已撤稿

| | |
|---|---|
| Severity · 严重度 | error · 错误 |
| Fix · 修复 | none · 无 |

## English

Message:

    '{key}' has been {notice} (reported by {sources}). Cite it only if the text discusses the retraction.

**What it checks.** Crossref (with Retraction Watch's data), OpenAlex or PubMed marks the cited work as retracted or withdrawn by its publisher. A partial retraction is a warning.

**When it can be wrong.** The notice is attached to the work's own DOI, so a wrong match is unlikely; a retraction is very rarely reversed.

**What to do.** Remove the citation, unless the text discusses the retraction itself; then silence it with the reason.

To silence it for one entry once you have checked it, put a comment above the entry:

    % preflight: ignore[REF004] reason="..."

To turn it off for the whole project: `ignore-rules = ["REF004"]` in the project's settings.

## 中文

消息：

    '{key}' 已{notice}（依据：{sources}）。除非正文讨论的就是撤稿本身，否则不应引用。

**检查什么。** Crossref（含 Retraction Watch 的数据）、OpenAlex 或 PubMed 标记被引作品已撤稿或被出版方撤回。部分撤稿报为警告。

**什么时候可能误报。** 撤稿声明关联在作品自己的 DOI 上，误配的可能很小；撤稿被撤销的情况极少。

**怎么处理。** 删除该引用；如果正文讨论的就是这次撤稿，可以注明原因后消除。

核对之后，如需对某个条目消除此规则，在条目上方加注释：

    % preflight: ignore[REF004] reason="..."

对整个项目关闭此规则：在项目设置中写 `ignore-rules = ["REF004"]`。
