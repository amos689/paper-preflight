# paper-preflight

[English](README.md) · **简体中文**

> **状态：预览前（pre-alpha），正在开发中。** 目前还不能用于实际论文。
> 首个公开版本（v0.1）计划于 2026 年 11 月发布。

**投稿前的论文完整性闸门——每条参考文献都对照真实学术数据库核验，不靠大模型猜，不乱扣"伪造"帽子。**

paper-preflight 读取你的 LaTeX 源文件（`.tex`、`.aux`、`.bib`），把每一条参考文献拿到真实学术数据源（Crossref、DataCite、OpenAlex、arXiv、dblp 等）上核对：

- 被引文献是否真实存在？
- 标题、作者、年份、出处、DOI 等元数据是否正确？
- 是否已撤稿？你引用的预印本是否已经正式发表？

它会给出可审阅、确定性的 BibTeX 修复补丁，既能给人用，也能给 Claude Code、Codex、Gemini CLI 等编码智能体和 CI 用。

## 设计原则

- **源码优先**：以你的 `.tex`/`.bib` 为准，PDF 抽取只作低置信补充。
- **正面确认，否则弃权**：只有真实记录确认时才算"已核实"。来源限流、宕机或根本不收录时，结论是"无法确定"，绝不是"未找到"。
- **判决路径不用大模型**：任何字段都不由语言模型生成。
- **中性措辞**：只陈述观察（"在 Crossref、OpenAlex、dblp、arXiv 中均未找到，四个来源均已应答"），不作指控。
- **本地优先、零遥测**：只把*被引文献*的元数据（DOI、标题、作者）发给上述公开学术接口；你的论文正文不会离开你的电脑。

## 我们绝不做的事

帮助规避查重或 AI 文本检测（降重、降 AI 率）、爬取付费墙或反爬保护的网站、替你推荐或"补全"参考文献、点名羞辱作者。
