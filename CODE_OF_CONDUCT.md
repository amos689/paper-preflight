# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and focus on the work. Harassment,
personal attacks and discriminatory language are not tolerated.

Because this tool deals with research integrity, one extra rule applies: **do not use issues,
discussions or pull requests to accuse named authors of misconduct.** Report tool behaviour,
not people.

Report unacceptable behaviour privately to the maintainers via GitHub's private reporting
features. Maintainers will review reports promptly and confidentially.
